Planned Value (PV / BCWS) PV = Planned % × BAC Budget authorized for work scheduled by the cutoff date.
Earned Value (EV / BCWP) EV = Physical % × BAC Budgeted value of physical work actually completed.
Cost Variance (CV) CV = EV - AC Difference between value earned and cash spent. Negative = Over budget.
Schedule Variance (SV) SV = EV - PV Value delivered versus scheduled. Negative = Behind schedule.
Cost Performance Index (CPI) CPI = EV / AC Efficiency ratio. Value earned per Rupee/Dollar spent.
Schedule Performance Index (SPI) SPI = EV / PV Velocity ratio. Speed of progress compared to baseline plan.
Estimate at Completion (EAC) EAC = BAC / CPI Projected final cost assuming current cost efficiency continues.
Variance at Completion (VAC) VAC = BAC - EAC Projected bottom-line budget surplus or overrun at finish.
To-Complete Index (TCPI) TCPI = (BAC - EV) / (Target - AC) Cost efficiency required on remaining work to finish within target.
