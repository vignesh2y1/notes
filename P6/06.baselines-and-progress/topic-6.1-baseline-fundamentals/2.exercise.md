### Question 4: The Database Column Anti-Pattern

```sql
    id UUID PRIMARY KEY,

    activity_code VARCHAR(32) NOT NULL,
    current_start TIMESTAMPTZ,
    current_finish TIMESTAMPTZ,
    baseline_start TIMESTAMPTZ,
    baseline_finish TIMESTAMPTZ
);
```
1. Explain three critical failure modes of this schema when handling scope changes, activity deletions, and network logic adjustments.
2. How does Primavera P6's "Deep Project Clone" architecture solve each of these three failure modes?
