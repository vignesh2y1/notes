## 🧠 Section A: Conceptual & Format Specification Principles

3. What is the semantic meaning of the relationship predicate types `PR_FS`, `PR_SS`, `PR_FF`, and `PR_SF` in table `TASKPRED`?

### Question 2: Memory & GC Overhead in Naive Go Parsers
A developer writes a parser that reads an entire 50MB `.XER` file into memory via `os.ReadFile` and uses `strings.Split(string, "\n")` followed by `strings.Split(line, "\t")`.
1. Calculate the approximate number of heap allocations and string objects generated if the file contains 1,200,000 lines and an average of 20 columns per line.
2. Explain the impact of this allocation pattern on Go's runtime garbage collector (mark-and-sweep phase, STW pauses, and CPU cache misses).
3. How does using a streaming `bufio.Reader` combined with reusable byte slices (`[][]byte`) eliminate these allocations?

%T	TASKPRED

3. Identify the predecessor activity ID of `ACT-TRN` and decode the relationship type and lag duration in calendar days (assuming an 8-hour workday).
