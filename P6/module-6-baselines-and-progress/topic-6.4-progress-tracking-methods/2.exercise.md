### Question 3: Out-of-Sequence Logic Resolution
During site execution on a solar power plant, physical execution frequently deviates from planned network topology:
```text
┌─────────────────────────────────┐           ┌─────────────────────────────────┐
│     Activity A: Trenching       │    FS     │   Activity B: Cable Pulling     │
│   Original Duration: 10 Days    │ ────────► │   Original Duration: 8 Days     │
└─────────────────────────────────┘           └─────────────────────────────────┘
```
At Data Date ($DD = \text{Day } 4$):
* Activity A has recorded $AD = 4\text{ days}$, $RD = 6\text{ days}$ (Not finished).
* Activity B has recorded an $AS = \text{Day } 3$, $AD = 1\text{ day}$, $RD = 7\text{ days}$ (Started out of sequence).

1. How does the **Retained Logic** scheduling mode handle Activity B's Remaining Duration during the forward pass? Where is the remaining work scheduled?
2. How does the **Progress Override** scheduling mode handle Activity B's Remaining Duration?
3. Which method is mandated by standard international contracts (e.g., FIDIC, US Army Corps of Engineers), and why?

### Question 6: The Earned Value Distortion Trap

  - Planned Duration: 20 days.
  - $\text{BAC} = \$100,000$.

1. Compute the reported % Complete, Earned Value ($\text{EV}$), and Schedule Variance ($\text{SV} = \text{EV} - \text{PV}$) for Activity X if the scheduling system naively uses Duration % Complete for EVM. (Assume Planned Value $\text{PV} = \$75,000$).
2. Compute the true Earned Value and Schedule Variance for Activity Y using Physical % Complete.
