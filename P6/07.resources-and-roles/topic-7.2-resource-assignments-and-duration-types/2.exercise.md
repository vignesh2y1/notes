### Question 3: State Transition Matrix Proofs
For each scenario below, determine the exact mathematical response of the scheduling engine:
1. An activity has `DT_FixDurUnits`. The initial state is $D = 10\text{ days}$, $U = 80\text{ hours}$, $R = 8\text{ hrs/day}$. The user edits Duration to $D = 20\text{ days}$. What are the new values of $U$ and $R$?
2. An activity has `DT_FixDurQtyTime`. Initial state: $D = 10\text{ days}$, $U = 80\text{ hours}$, $R = 8\text{ hrs/day}$. The user edits Duration to $D = 15\text{ days}$. What are the new values of $U$ and $R$?
3. An activity has `DT_FixQty`. Initial state: $D = 10\text{ days}$, $U = 100\text{ hours}$, $R = 10\text{ hrs/day}$. The user doubles the crew, changing $R = 20\text{ hrs/day}$. What are the new values of $D$ and $U$?
4. An activity has `DT_FixQtyTime`. Initial state: $D = 10\text{ days}$, $U = 100\text{ units}$, $R = 10\text{ units/day}$. The client issues a change order expanding the scope to $U = 250\text{ units}$. What are the new values of $D$ and $R$?
