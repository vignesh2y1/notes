## 🧠 Section A: Conceptual & Algorithmic Foundations

### Question 1: The "Pure Math" Fallacy
A junior backend engineer on your team writes the following utility function for a Next.js Gantt chart microservice:
```go
func CalculateFinishDate(startDate time.Time, durationDays int) time.Time {
    return startDate.AddDate(0, 0, durationDays)
}
```
1. Explain at least three physical, contractual, or mathematical reasons why this function fails completely in an enterprise construction scheduling engine.
2. If an activity starts on Friday at 14:00 with a duration of 2 working days (16 working hours) on a standard 5-Day (8h/day, 08:00–17:00, 1h lunch) calendar, what is the exact finish timestamp? What does the naive function output instead?

### Question 9: Precomputed Cumulative Working Minutes ($O(1)$ Range Query)

1. Explain how `CumulativeMins` enables computing the working minutes between any $m_1$ and $m_2$ in $O(1)$ time.
2. What are the space requirements of `[1441]int` in Golang? Is this acceptable for a production server running tens of thousands of CPM activities?
