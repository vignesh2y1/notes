## 💻 Section D: Golang Engine & Algorithmic Implementation

### Question 9: Implementing `ResolveGoverningCalendar`
Write a production-ready Golang function:
```go
func ResolveGoverningCalendar(
    act Activity, 
    assignments []ResourceAssignment, 
    calRepo CalendarRepository, 
    resRepo ResourceRepository,
) (*Calendar, error)
```
Your implementation must:
1. Inspect `act.Type`.
2. If `TASK_DEPENDENT`, fetch and return the activity's assigned calendar.
3. If `RESOURCE_DEPENDENT`, find the resource where `IsPrimary == true`. If found, fetch and return that resource's calendar.
4. If `RESOURCE_DEPENDENT` but no resource has `IsPrimary == true`, fall back to the first assigned resource's calendar.
5. If `RESOURCE_DEPENDENT` but `assignments` is empty, log an engine warning and fall back to `act.CalendarID`.
6. Return descriptive errors for missing IDs.

### Question 11: Detecting Overallocation on Task Dependent Activities
When an activity is `TASK_DEPENDENT`, its dates are calculated using the activity calendar. However, the scheduling engine must audit assigned resources to identify overallocation or non-working day violations.

Write a Golang function:
```go
type ConflictReport struct {
    ResourceID      string
    Date            string
    DemandedMinutes int
    ConflictReason  string
}

func DetectResourceConflicts(
    act Activity, 
    res Resource, 
    resCal Calendar,
) []ConflictReport
```
The function must walk through each day of the activity's execution span (`[act.EarlyStart, act.EarlyFinish]`) and detect any day where the activity demands work but `resCal` designates the day as non-working or provides fewer working minutes than demanded.
