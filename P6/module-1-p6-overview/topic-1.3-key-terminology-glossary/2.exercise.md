### Question 1: Total Float vs. Free Float Calculation & Field Implications
Consider a sub-network in the Surya 100MW Solar IPP for the **Inverter Station #1 Interconnection**:

```
[Act A: Cast Transformer Pad] (OD: 5d)
       │
       ├─────────────────────────────────┐ (FS, Lag = 0)
       │ (FS, Lag = 7d curing)           │
       ▼                                 ▼
[Act B: Mount 33kV Transformer] (OD: 3d) [Act C: Install Cable Tray Supports] (OD: 4d)

       │ (FS, Lag = 0)                   │ (FS, Lag = 0)
       ▼                                 ▼
```

* Project Data Date = **Day 1** (08:00). All activities use a continuous 7-day, 8-hour working calendar.
* Activity A starts on Day 1.
* The Project Finish Milestone requires Activity D to finish by the end of **Day 20** (Late Finish of Activity D = Day 20).

1. Perform the Forward Pass and calculate Early Start (ES) and Early Finish (EF) for Activities A, B, C, and D.
2. Perform the Backward Pass and calculate Late Start (LS) and Late Finish (LF) for Activities A, B, C, and D.
