### Question 4: Multi-Grant Additive Union vs. Hierarchical Shadowing
Suppose User Rajesh has two distinct security grants in the system:
* **Grant 1:** Assigned to parent OBS node `OBS-DIR-NORTH` with profile `Executive Viewer` (Read-only, no activity edits).
* **Grant 2:** Assigned to child OBS node `OBS-PM-RAJ` with profile `Project Manager` (Full read/write, F9 scheduling, baseline creation).
1. When Rajesh attempts to edit activity dates on `PRJ-SOL-100-RAJ` (whose Responsible Manager is `OBS-PM-RAJ`), should the system permit or deny the action?
2. Explain why P6 security uses an **Additive Union** model rather than a "first-match-wins" or "most-restrictive-wins" model across multiple grants.
3. What is the potential vulnerability if an authorization engine implements a "least-privilege-wins" model in a multi-tier hierarchy?
