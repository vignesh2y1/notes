* Project B: *220kV Pooling Substation & Grid Interconnection* (managed by the Transmission Grid SBU).
Activity `A1040` ("Commercial Operations Date — COD") in Project A has a Finish-to-Start dependency on Activity `B2040` ("Energize 220kV Feeder Bay") in Project B.
1. When Project A is opened in isolation, how does Primavera P6 display Activity `B2040`?
2. Can the scheduler of Project A edit the duration, relationships, or assigned resources of Activity `B2040` while working inside Project A? Explain the security boundary.
3. If Project B's scheduler delays Activity `B2040` by 60 calendar days, what happens to Project A's Early Dates and Total Float:
   - When Project A is not opened?
   - When Project A is subsequently opened and scheduled alone?
   - When both projects are opened together and scheduled in a unified multi-project run?

2. How can a delay inside the Solar Farm cause **Negative Float** to appear on activities inside the Grid Substation? Trace the CPM backward pass across the relationship.
3. Why do enterprise PMOs mandate the use of **Interface Milestones** (Handoff Milestones) rather than allowing direct task-to-task cross-project links between independent contractor schedules?

1. Draw the directed graph showing the circular dependency loop between Project A and Project B.
2. Why did the legacy scheduling engine hang, and how does Tarjan's algorithm detect and reject this transaction in under 20 milliseconds?
3. What engineering mitigation (e.g., temporary mobile diesel generators for auxiliary power) should be modeled in the schedule to break the circular dependency in the physical world?
